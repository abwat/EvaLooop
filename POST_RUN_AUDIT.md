## Language audit

Ten different task IDs per model are selected: two shortest summaries, four with the largest
backtick-content share, and four seeded random remaining summaries. Ties use task ID and cycle.
The 30 records and decisions are in `language_audit.csv`. The instruction was:

> Read the explanatory prose, ignoring copied Python identifiers, code, and example literals.
> Classify it as Spanish prose, Spanish with minor English prose, substantially mixed,
> English, or unclear. Flag English words outside identifiers and literals. Do not classify
> semantic correctness as language compliance.

Codex (GPT-6) reviewed all 30: 29 contain Spanish prose and one Qwen2.5 MBPP/478 cycle-2
summary contains the English word “effectively.” All 30 are predominantly Spanish. This
qualitative check is AI-assisted, not independent human validation or a population estimate.
Lingua's binary result does not establish that every summary is exclusively Spanish.

## Sensitivity and planning history

Removing a task pair when either arm has any capped generation leaves 97 CodeQwen pairs
(effect +0.411), 98 OpenCoder pairs (−0.235), and all 100 Qwen2.5 pairs (−0.391). This includes
capped cycle-10 summaries, even though they are not used to generate another scored cycle.
Cap status is post-treatment; exclusion is a sensitivity check, not a causal adjustment.
The direction of cap-induced bias cannot be established from the logs alone.

The archived protocol already names Lingua and the final three models, defines quadratic ASL
as the primary contrast, and specifies Wilcoxon with Pratt zeros without explicitly choosing
cycle-count versus ASL inputs. Earlier discussion considered Gemma and cycle-count tests.
There is no dated change log establishing when or why every planning change occurred; no
replacement rationale is asserted retrospectively. Testing successful-cycle differences gives
the same Wilcoxon statistics and p-values as ASL differences in these records (CodeQwen .098,
OpenCoder .263, Qwen2.5 .203). The hypothesis tests are still exploratory without verified
prospective registration.
Run `python scripts/posthoc_audit.py --cycle-tests` with SciPy installed to reproduce these tests.
